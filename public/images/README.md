# Site photographs

Every photo used on the public site lives in this folder. Which photo goes
where is set in `src/lib/site/images.ts` — to replace one, drop the new file
here and change its path there. Clear a path (`""`) to hide that photo; the
section falls back to its original design.

Use WebP (or JPG), about 1600 px wide, under about 300 KB, with no text or
logos inside the picture. The layout crops photos to fit, so keep the main
subject near the centre.
